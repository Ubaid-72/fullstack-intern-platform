# Full Stack Intern Platform

## Description
A full stack platform designed to manage interns, tasks, and collaboration through secure backend APIs and structured workflows.

## Tech Stack
- Node.js
- Express
- MongoDB
- HTML
- CSS
- JavaScript

## Features
- Intern management
- Task assignment and tracking
- Secure API endpoints
- Middleware-based architecture
- Modular backend structure

## Setup
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file using `.env.example`
4. Start the server using `npm start`

## Notes
This project was developed as part of a learning-based full stack development experience.
All sensitive environment variables and credentials have been excluded.
